Build 1 — Begin vibe coding your AI portfolio

Model: Sonnet · Time: 13 min

Design a portfolio website with AI in one prompt — Claude Code interviews you to gather what it needs.

Steps:

Create and enter a working folder: mkdir ai-builder then cd ai-builder.

Start Claude Code in that folder by typing claude; approve read/write permissions when asked.

Set model to Sonnet (/model), then paste the build prompt (interview-driven single-file HTML portfolio: Hero, About, Work, AI Projects grid with pre-filled "Coming Soon" cards, Contact).

Reusable prompt template:

Goal: Build me a complete portfolio website as a single self-contained HTML file. Interview me about any information you don't have before building.

Context: This is my AI Builder portfolio - a living showcase of everything I build throughout the program.

Rules:

- Google Fonts are the only allowed external resource

- Include these sections:

- Hero: "AI Builder Portfolio" with my name and title below

- About: 2-3 sentences, conversational, written like talking to a friend

- Work: 2-3 current focus areas or projects, each with a title and 1-2 sentence description

- AI Projects: A grid of cards - each with a project title, one-line description, a "How I Built This" link, and a "Documentation" link. Both links open a popup (leave popups empty for now). Pre-fill with these "Coming Soon" cards: Design System Skill, Portfolio Website, Voice Guide Skill, Email Manager Scheduled Task, Custom Workflow, Spreadsheet Analysis, Data Analysis Presentation, File Organization Process, AI Context File, Skills Library.

- Contact: Simple, clean footer with contact info



Tip: use voice dictation (Mac: Fn twice; Windows: Win+H) when Claude Code interviews you for bio/work content.

Go further: add an animated background to the portfolio.

Build 2 — Extract design elements and turn them into a reusable skill

Model: Sonnet (extraction) → Haiku (skill creation) · Time: 26 min

Pull exact colors, fonts, and layout rules from a site you love, then save them as a skill callable via /[your-skill-name].

Steps:

Pick a design-inspiration site (ideally your own company's site) and copy its URL.

In Claude Code with model set to Sonnet, paste the design-extraction prompt with the URL.

Copy the generated design guide.

Start a new Claude Code session in ai-builder, set model to Haiku, and paste the skill-creation prompt with the design guide as context.

Reference the resulting skill in future prompts via /[skill-name]-design.

Reusable prompt template — extract design guide:

Goal: Extract a structured design guide from this page that I can paste directly into a future prompt.

Context: I'm building a portfolio website and I want it to feel like this site. The site is at [paste your inspiration URL here].

Rules:

- Read the live page at the URL directly - sample the real colors and fonts, don't rely on general brand knowledge

- Extract: primary and accent colors (with exact hex codes), typography style and feel, layout approach, and 5 words that capture the overall vibe

- Format as a structured document - specific enough to reuse, not just general impressions



Reusable prompt template — turn guide into a skill:

Goal: Turn this design guide into a reusable skill called [site name, e.g. Google]-design.

Context: [Paste your design system document here]

Rules:

- Use /skill-creator to create the skill

- Save it to my Claude Code skills folder so I can use it in any session

- Don't run evals right now



Note: /skill-creator is Anthropic's built-in skill for building custom skills — it handles formatting and file placement.

Go further: create a skill variation for a specific output type.

Build 3 — Design your custom portfolio

Model: Sonnet · Time: 20 min

Combine the portfolio scaffold and design skill: style the portfolio, fill in the first two project cards, and publish it live.

Steps:

In Claude Code (in ai-builder), paste the styling prompt referencing your specific design skill — it builds out "Design System Skill" and "Portfolio Website" cards with "How I Built This" and "Documentation" popups.

Open the updated portfolio.html locally to preview (open portfolio.html on Mac / start portfolio.html on Windows, or double-click).

Iterate with follow-up prompts (adjust tone, colors, add animation, etc.).

Publish: go to builders.leland.ai → Join Cohort → upload portfolio.html → save the API key (acts as your edit password) → Publish → get shareable link.

Reusable prompt template — style + build cards:

Goal: Style my portfolio with my design skill and build out the first two AI Project cards.

Context: My portfolio HTML file is already saved in my working directory from Build 1. My design skill is /[your-style]-design.

Rules:

- Read /[your design skill] before writing any CSS

- Google Fonts are the only allowed external resource

- Interview me about any info you don't have

- Build these two cards:

Card 1 - "Design System Skill":

- "How I Built This" popup: A visual step-by-step: 1. Found an inspiration website 2. Used Claude Code to read the site and extract the design elements 3. Used /skill-creator to turn it into a reusable skill 4. Now it works everywhere - type /[skill-name] and every build matches my style

- "Documentation" popup: Read my /[style]-design skill file and display everything without clicking: color swatches with hex codes, typography samples with specs, layout principles, and vibe words as styled tags. Style the popup using the design system itself.

Card 2 - "Portfolio Website":

- "How I Built This" popup: A visual step-by-step: 1. Started with a simple scaffolded HTML page 2. Applied my design system skill to style it 3. Claude interviewed me to fill in real content 4. Built out project cards as I completed each AI Builder session

- "Documentation" popup: Two sections - a list of techniques used and a list of key prompts for building your own portfolio with a design skill.

- Keep all other cards as "Coming Soon" with empty popups

- Update the existing portfolio HTML file in my working directory



Sample follow-up refinement prompts:

"Make the hero section feel more [adjective from the design system]"

"The about section is too formal. Rewrite it in a more conversational tone."

"Change the primary color to [hex from your design system]"

"Add a subtle animation to the hero section"

Go further: add extra portfolio sections.
