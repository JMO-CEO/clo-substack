Build 1 — Analyze your data in a spreadsheet

Time: 15 min

Merge, enrich, and summarize the college dataset with Claude Code — no formulas required.

Steps:

Open a terminal directly inside ai-builder (Finder "New Terminal at Folder" on Mac; File Explorer "Open in Terminal" on Windows), then run the download command above.

Ask Claude Code to summarize college-data.csv (row count, columns, value ranges, full school list). Run /compact afterward to keep context lean.

Ask Claude Code to explain how it plans to join in college_premium_by_state.csv, then merge it and suggest the most interesting things learnable from the combined data. Approve any code-execution or package-install prompts (press 1 + Enter). If installs keep failing: "Set up a clean Python environment inside my ai-builder folder and use it for the rest of this session." Run /compact again after the merge.

Pick insights to add as calculated columns (e.g., an earnings-to-debt ratio); have Claude Code compute them and document each calculation in a Methodology tab.

Pick 1–3 schools to follow for the rest of the session (alma mater, rival, dream school, etc.) — search the dataset first if unsure.

Ask Claude Code to create a "My Schools" tab in college-analysis.xlsx pulling just those schools' rows side-by-side.

Open college-analysis.xlsx (Excel or Google Sheets) and verify the My Schools tab, calculated columns, and Methodology tab are correct.

Notes: Claude Code will ask "Do you want to proceed?" before running code — this is normal per-action approval. /usage (formerly /cost) shows token usage at any time; a small non-zero baseline before you've typed anything is expected (system prompt/tool setup).

Go further: run this workflow on your own data.

Build 2 — Build charts that tell a story

Time: 15 min

Ask Claude Code to recommend and build 2 charts from the My Schools data, then surface the headline finding for the presentation.

Steps:

Run /compact to start lean. Ask Claude Code what charts would be most interesting, focused on the My Schools tab.

Pick 2 charts that are actually interesting to you.

Have Claude Code add them to college-analysis.xlsx as real, native spreadsheet charts (not static images) by editing the existing file in place — using the Google Sheets or Excel track that matches your setup. For Excel, specify openpyxl (edits in place) rather than xlsxwriter (creates new files only and can lose tabs/data when rebuilding the workbook).

Review and refine with short, specific directives (label size, colors, emphasis) rather than re-writing the whole prompt.

Ask Claude Code to surface 3 surprising findings framed as click-worthy headlines, with specific numbers required.

Pick the strongest finding as your presentation headline and save it — Build 3 starts in a fresh session and it won't carry over automatically.

Run /compact before ending the session.

Share: post your favorite chart in cohort Slack.

Go further: create additional charts; brand your charts with your design skill.

Build 3 — Structure your presentation

Time: 10 min

Turn the data findings into a slide-by-slide outline, then a low-fidelity ASCII mock-up before designing.

Steps:

Start a fresh Claude Code session (Ctrl+C to exit, then claude again in the same folder). Ensure college-analysis.xlsx is present and the Build 2 headline finding is on hand.

Ask for 6 slides or fewer, one point per slide, with slide titles that name a specific finding rather than a topic label (e.g. "MIT grads earn $22K more than the national average" vs. a generic "Earnings Analysis").

Review the outline — this is the cheapest point to edit, before design.

Ask Claude Code to build a low-cost ASCII mock-up to lock in structure before the expensive design pass. Run /compact before Build 4.

Review the mock-up and fix structural issues before moving on.

Share: post your best slide title in cohort Slack.

Go further: use web research instead of the spreadsheet; run this for your own work.

Build 4 — Build your slide deck

Time: 20 min

Turn the outline and mock-up into a polished presentation with Claude Code or Claude Design, applying the Session 1 design skill.

Two options:

Option A — Claude Design: go to claude.ai/design → New Project → Slide Deck. Name it, set Design System to None (bringing your own skill), optionally enable Speaker Notes. Attach presentation-mockup.txt and the design-skill .md file with the paperclip icon (not Import), then ask it to build the deck. First render takes 1–2 minutes.

Option B — Claude Code: stay in the terminal and have Claude Code build a self-contained college-presentation.html from the mock-up, applying the design skill.

Iteration guidance:

Good feedback: "The text on slide 3 is wrapping and looks cramped. Fix the layout so it reads as a single column." / "The header color on slide 5 doesn't match my primary brand color. Update it."

Poor feedback: "Make it look better." (too vague, wastes tokens)

Batch multiple fixes into one message rather than sending them one at a time.

Run /compact once satisfied, to clear iterative feedback history before Build 5.

Go further: add keyboard navigation and a speaker-notes toggle; build an animation skill and animate key slides.

Build 5 — Export and add to your portfolio

Time: 15 min

Export the deck and log the two new builds on the portfolio.

Part 1 — Export:

Claude Design: click Export (top-right) → choose PDF (recommended), PowerPoint, or HTML.

Claude Code: run the export matching your target format.

Before sharing: open the exported file and confirm slide order and text readability.

Share the presentation via email, Google Drive, or Slack.
