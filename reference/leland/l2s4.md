Build 1 — Create a custom morning brief using your second brain

Model: Sonnet · Time: 35 min

Design (no pasted prompt — you write it) a scheduled morning brief connected to the second brain and daily tools.

Steps:

Confirm calendar, email, and a messaging tool (Slack or Teams) show as connected in the Customize tab. Enterprise restrictions blocking some tools are fine.

Pick 3+ sections for the brief from the menu below — the "what to build next" section is required, since Build 2 uses its recommendation.

Design the routine prompt yourself with the agent, using the Goal / Context / Rules framework (see below), specifying the sections, which connected tools to use, and where to pull from the Session 3 wiki.

Ask the agent to mock today's brief from the draft prompt; iterate on the prompt until the output reads the way you want every morning.

Create the routine in Claude Code Desktop → Routines → New routine → Local (reads local files, needs your machine) → name morning-brief → select the my-agents folder → paste the finalized prompt → schedule weekdays at a time your computer will reliably be open.

Run once and grade the output — refine the prompt further if needed.

Reference: morning brief section menu

Section

What it does

Messages that need attention

Summary of important messages from email, Slack, or other sources

What matters today

Today's calendar; status/context on top projects pulled from the wiki

What to act on

Action items for the day, drafted replies ready for review, follow-ups from the day before

What to build next (required)

Pulls from the automation roadmap and work activity to recommend the next automation to build

External info

A free API, or asking AI to check specific websites daily (stock market, weather, news headlines, etc.)

Framework for designing the routine prompt yourself

Goal: Create a prompt that will send you a morning brief every day

Context: Add in some bullet points describing your sections from step 2. Explain which connected tools it should use, where it can reference your second brain from session 3, and any other helpful context.

Rules: What constraints do you want to give the agent? Should your brief prompt specify it needs to be readable in 60 seconds, short bullet points only, or having every section name its data source? Do you want to ask your agent to push back on your brief proposal or ask questions if anything is unclear?



Recommended rule to add: have the agent structure the routine prompt itself using the Goal / Context / Rules framework.

Go further: add a live data section with an API; add a weekly feedback loop; run it with your laptop closed.

Build 2 — Create a custom automation from your automation roadmap

Model: Sonnet · Time: 35 min

Scope and ship a second automation MVP, either the morning brief's "what to build next" recommendation or another roadmap card.

Steps:

Pick the automation — from the morning-brief recommendation, the roadmap, or a borrowed example if nothing feels right yet.

Create a folder for it inside my-agents, then write a short markdown scope doc answering the five scoping questions below (in any text editor).

Give the agent the scope doc and ask it to identify any additional tool connections/scopes needed.

Ask the agent to help write the routine prompt using the same Goal / Context / Rules framework as Build 1, grounded in the scope doc and referencing the wiki where relevant.

Mock a run and iterate on the prompt until output matches the scope doc.

Create the routine in Claude Code Desktop → Routines → New routine → Local → name it after the automation → select its folder → paste the finalized prompt → set the schedule to the cadence from the scope doc (daily is rarely right — weekly is often the better default).

Run once and judge the output against the scope doc; edit and re-run if the judgment call or output placement is off.

Update the roadmap: move this automation's card to Done, add any new ideas surfaced today to Suggested.

Reference: five-question automation scope doc

Question

What to answer

Task

What do you want to automate? What happens now, and what should happen automatically instead?

Trigger

What starts it — a schedule, an arriving event (email, message, form submission), or a manual kickoff?

Context

What data or tools does it need — inbox, calendar, second brain, spreadsheet, website?

Judgment

What should the AI decide or do mid-workflow — what judgment call or action is being handed off?

Output

Where does the output go and what does it look like — Slack message, drafted email, file, sheet row?

Framework for the routine prompt

Goal: Create a prompt for [describe your routine]

Context: Give it your scope doc from step 2. Explain which connected tools it should use, where it can reference your second brain from session 3, and any other helpful context.

Rules: What constraints do you want to give the agent? Should your brief prompt specify it needs to be readable in 60 seconds, short bullet points only, or having every section name its data source? Do you want to ask your agent to push back on your brief proposal or ask questions if anything is unclear?



Go further: turn the scoping questions into a reusable skill; wire in the wiki; put an eval on it.
