# drafts/ - weekly folder contract

One folder per week: `drafts/YYYY-MM-DD-slug/`. Tue night `clo-weekly` builds it.
Wed `clo-ship` gates it. 9 files, all non-empty, or the run fails.

- article-draft.md (1000 to 1600 words, Next Week plus For now close)
- note-1.md (Mon Director) through note-5.md (Fri Executive), each 400 ideal / 600 max chars
- comic-pack.md (5 Note sections plus villain sheet plus evaluation scores)
- research-brief.md (3 tracks with links, dates, confidence notes)
- meta.json (week, status, villain, leland cites, manual-60 sources)
