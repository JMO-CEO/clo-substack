# drafts/ - weekly folder contract

One folder per week: `drafts/YYYY-MM-DD/`. Tue 10pm Action builds it.
Wed `clo-ship` gates it. 10 files plus meta.json, all non-empty, or the run fails.

Core (every week):
- article-draft.md (1000 to 1600 words, Next Week plus For now close)
- note-1.md (Mon Director) through note-5.md (Fri Executive), each 400 ideal / 600 max chars
- cover.svg plus cover.png (brand lock v1, hook substituted)
- image-prompt-pack.md (5 sections, locked overlay verbatim)
- video-script-pack.md (2 clips max, fal.ai endpoint plus params plus sonic tag)
- research-brief.md (3 tracks with links, dates, confidence notes)
- meta.json (date, week, rotation source, rotation track, villain, leland cites, fal endpoint, word counts, sources, status)

Rotation (ONE per week, ISO week mod 4):
- Week 0: platform-brief.md (top Substack articles plus feature recommendations)
- Week 1: dm-pack.md (5 mixed law plus comics collab drafts, sending manual)
- Week 2: image-prompt-lab.md (image plus video prompt tips, recommendations only)
- Week 3: article-prompt-lab.md (article writing prompt tips, recommendations only)
