# Leland Ops (CLO edition)

Reference library lives at reference/leland/l1s1.md through l3s4.md, plus
certificates in reference/leland/certificates/ (Level 1 and Level 2 proof).

## Rules

1. Cite sessions by ID in brackets: [L1S1], [L2S3]. One cite per build step shown.
2. Every article that demonstrates a build must name: what was built, which session
   taught the pattern, what was adapted for legal work, what broke on first try.
3. Never invent session content. If the cite is not in the reference files, mark it
   UNVERIFIED and ask Jared.
4. Certificates may be referenced as proof of completion (L1 plus L2 done), never as
   legal authority.
5. When Jared finishes a new level, add its syllabus files here and update MEMORY.md.
