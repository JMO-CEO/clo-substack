# Prompt lab phase (CLO weekly, rotation weeks 2 and 3)

Goal: keep our prompts ahead of the field. Output is recommendations only. Never edit agents, skills, prompts, configs, or workflows in any run. Applying recommendations is a human decision on a later build.

The runbook calls ONE section per rotation week. Max 3 searches per run.

## Section A: image and video lab (rotation week 2)

1. Find the best new tips for image prompts (composition, style control, character consistency, comic and manga looks) and video prompts (camera moves, timing, native audio direction, fal.ai model params).
2. Write drafts/YYYY-MM-DD/image-prompt-lab.md: each tip in one line, then a concrete recommendation for our files, each tagged with the file it would touch (prompts/brand-clo.md, prompts/clo-comic/frames.md, prompts/visual-clo.md, clo-visual-builder agent) and the expected effect.

## Section B: article writing lab (rotation week 3)

1. Find the best new tips for article writing prompts (hooks, structure, voice preservation, research grounding, CTA design for newsletters).
2. Write drafts/YYYY-MM-DD/article-prompt-lab.md: each tip in one line, then a concrete recommendation for our files, each tagged with the file it would touch (prompts/article-clo.md, clo-article-writer agent, clo-persuasion-coach, clo-humanize skills) and the expected effect.
